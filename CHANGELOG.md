# История изменений

## 2.0 — 2026-10-05

### Добавлено
- GSM SMS-драйвер, очередь, worker, состояния частей и ручное разрешение неопределённых результатов.
- Локальный запуск через `python test.py runserver`.
- Docker Compose: PostgreSQL, migrations, Gunicorn, Caddy и optional SMS worker.
- Скрипт backup, страницы аккаунта, смены пароля и аудита.

### Изменено
- Адаптивный интерфейс, локальный Noto Sans и упрощённые формы.
- Удалён выбор языка из форм ученика и книги.
- Добавлена защита от устаревшего редактирования фонда.
- Усилены ограничения входа, проверка импорта и изоляция доступа.

### Проверка
- 73 локальных теста прошли; 2 теста PostgreSQL concurrency пропущены в SQLite.
- Реальные Docker deployment, GSM/SIM и банковская интеграция не подтверждены локальным прогоном.

## Оформление репозитория — 2026-10-06

- Русскоязычный README, скриншоты и описание инженерных решений.
- Сохранён отдельный таджикский quick-start.
- Добавлены рекомендации по commit-ам и ревью изменений.

История предыдущих этапов доступна в Git. Даты здесь обозначают подготовку изменений, а не создание GitHub Release.
