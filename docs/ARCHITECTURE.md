# Архитектураи қабулшуда

## Интихоб

**Монолити модулӣ: Django + DRF + PostgreSQL.** Django аутентификатсия, ORM, мигратсия ва маъмурият медиҳад; DRF қабати API аст. FastAPI низ имконпазир аст, аммо барои ҳамин лоиҳа сохтани ин бахшҳои маъмурӣ кори иловагӣ мешавад. Redis, Celery ва microservice дар оғози кор лозим нестанд; танҳо баъди пайдо шудани вазифаи воқеии навбатӣ илова мешаванд.

| Қабат | Масъулият |
|---|---|
| Templates + CSS/JS | Формҳо, ҷадвалҳо, preview ва interaction |
| UI views / DRF API | CSRF, validation, tenant/role permission |
| Services | Қоидаҳои иҷора, анбор ва маблағ; atomic commands |
| Models / PostgreSQL | Schema, constraints, row locks ва таърих |
| Explicit local demo | SQLite барои single-user preview; backend-и асосӣ PostgreSQL |


## Модулҳои мантиқӣ

| Модул | Вазифа |
|---|---|
| Мактаб ва дастрасӣ | School, Membership, login; бе register |
| Хонандагон | Student ва Enrollment барои ҳар соли таҳсил |
| Каталог ва анбор | Book → Edition → Stock; таърихи ҳаракат |
| Тариф ва маҷмӯа | Тарифи тасдиқшуда барои нашр/сол; 5–15 мавқеъ |
| Иҷора | Пешнамоиш → ислоҳи истисно → тасдиқ |
| Биллинг | Invoice, Payment, бақия ва истиноди дохилӣ |
| Баргардонидан | Солим / осебдида / гумшуда; мустақил аз пардохт |
| Аудит | Сабти амалҳо дар ҳамон транзаксия |

Дар баста ҳамаи модулҳо дар як app-и Django нигоҳ дошта шудаанд; ҷудоии API/model/service воқеӣ аст. Агар ҳаҷм зиёд шавад, онҳоро ба app-ҳои алоҳида бе тағйири қоидаҳои тиҷоратӣ ҷудо кардан мумкин.

## Қоидаҳои ҳалкунанда

1. Мактаб аз корбари воридшуда гирифта мешавад. API `school_id`-и фиристодаи браузерро қабул намекунад. Ҳар query бо мактаб маҳдуд мешавад; Edition тавассути Book.school.
2. Хонанда шахси доимӣ аст; синф, гурӯҳ ва забони ҳар сол дар Enrollment. Ҳисобҳои гузашта ҳангоми гузариш ба синфи нав боқӣ мемонанд.
3. Book номи китобро нигоҳ медорад; Edition нашр, сол ва рамзи нашрро. Ду нашри як сол низ бо рамзҳои ҷудо мумкинанд.
4. Ҳангоми иҷора ном, соли нашр ва маблағ дар LoanLine snapshot мешаванд. Тағйири тариф ҳисоби пешинаро дигар намекунад.
5. Пешнамоиш кафолати бақия нест. Дар тасдиқ ҳамаи интихоби нашр, тариф, маблағи интизорӣ ва бақия аз нав санҷида мешаванд.
6. Иҷора, камшавии анбор, Invoice, ҳаракати анбор ва аудит ҳама якҷоя commit ё rollback мешаванд.
7. UUID token такрори тасдиқ/пардохтро муҳофизат мекунад. Ҳамон token + ҳамон payload натиҷаи пешинаро медиҳад; payload-и дигар 409.
8. Нусхаи набуда интихоб ва ҳисоб намешавад. Додани қисми маҷмӯа `allow_partial=true` мехоҳад.
9. Баргардонидани китоб қарзро сифр намекунад. Баргардонидани маблағ ва ҷарима ҷараёнҳои алоҳидаи ояндаанд.

## Ҳамзамонӣ ва ҳудуди кафолат

Ҳар амали тағйирдиҳанда `transaction.atomic` дорад. Барои соддагии версияи аввал сатри School бо `select_for_update` қулф мешавад: як амали кӯтоҳ барои як мактаб дар як вақт; мактабҳои дигар мустақиланд. Сатрҳои Stock низ бо тартиби ID қулф мешаванд. Дар дохили қулф дархости шабакавӣ ё хондани файли калон иҷро намешавад.

Ин ба throughput-и як мактаб маҳдудият медиҳад. Пеш аз ҳазорон амали ҳамзамон load test лозим аст; баъд қулфҳоро ба сатҳҳои Student/Stock/Invoice хурд кардан мумкин.

Ҷудоии мактаб ҳоло дар application мебошад, PostgreSQL RLS фаъол нест. Бевосита навиштан ба база ё модели ORM берун аз services қоидаҳои байни ҷадвалҳоро давр зада метавонад. Барои production ҳуқуқи DB, audit ва роҳҳои навиштани маълумотро маҳдуд кунед.

Дастрасии марказӣ тавассути superuser аст. Маъмури мактаб superuser нест. Панели admin барои тағйири мустақими маблағ ва бақия истифода намешавад.

## Дизайни интерфейс

Менюи кӯтоҳ: Пештахта, Хонандагон, Анбор, Додани китоб, Ҳисобҳо. Рангҳои кабуди торик ва сабзи ором; ҳар саҳифа як амали асосӣ. Ҷадвалҳои хондашаванда, ҷустуҷӯ ва филтри синф/гурӯҳ. Тарифро аз сол худкор тахмин накунед.

Саҳифаи додан: синф/гурӯҳ → ҷустуҷӯи хонанда → маҷмӯаи пуршуда → танҳо иваз/набудани китоб → ҷамъбасти маблағ → як тасдиқ. Select-и сол барои ҳар китоби ҳар хонанда такрор намешавад.

Дар версияи 0.2 формҳои кории хонанда, импорт, анбор, маҷмӯа, иҷора, пардохт, баргардонӣ ва ҳисобот омодаанд. docs/PROGRESS.md ҳолати дақиқ ва маҳдудиятҳоро нигоҳ медорад.
