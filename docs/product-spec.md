# KitobYor · маҳсулот 1.0

Мақсад: масъули китобхона хонандагон ва китобҳоро зуд ворид карда, ба хонанда дар як экран чанд китоб диҳад ва пардохтро осон сабт кунад.

## Саҳифаҳо

Login бо панели тасвири хираи китобхона ва формаи равшан; register нест. Пештахта бо менюи чап, topbar-и мактаб/сол/корбар, тасвир ва рақамҳои воқеии база. Хонандагон бо ҷустуҷӯ, синф, гурӯҳи A–E, контакти волидайн, таҳрир ва додани китоб. Анбор танҳо ном, синф, сол, бақия ва нарх дорад. Маҷмӯаҳо ихтиёрӣ сохта шудаанд, дар ҷараёни асосӣ истифода намешаванд.

Додани китоб: хонанда → китобҳои синфи худаш → галочка → соли нашр/нарх → маблағи ҷамъ → як тасдиқ. Ҳар нашр нархи мустақили воридкардаи масъул дорад. Иҷораҳо: рақами дохилии пардохт, ном, шумораи китобҳо, total, status ва «Пардохт шуд». Ҳисобот: маблағи иҷора, маблағи сабтшуда, пардохтшуда/нашуда ва CSV. Қарз ва баргардонӣ бахши UI надоранд.

## Марзҳои 1.0

Ягон рақами дохилӣ аз омӯзгор пурсида намешавад. Мактабро оператор месозад; омӯзгор login мегирад. Рақами пардохт ҳоло танҳо дар KitobYor амал мекунад. Пардохти бонк/Госуслуги ва SMS баъди API/шартномаи provider фаъол мешаванд. Нақдӣ ҳоло дастӣ тасдиқ мешавад. Хонандаи синфи 10 китобҳои синфи 10-ро мебинад. Як экран ба додани қисми дилхоҳи китобҳои дастрас иҷозат медиҳад, checkbox-и иловагии тасдиқ надорад.

Барои production: пайвасти provider, rollover-и соли таҳсил, маъмурияти марказӣ, backup/restore ва санҷиши PostgreSQL заруранд. 1.0 локалӣ намоишшаванда аст, сервери production нашр нашудааст.
