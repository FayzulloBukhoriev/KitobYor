> Лоиҳаи мавҷудаи KitobYor-ро идома деҳ. Аввал AGENTS.md, README.md ва docs/PROGRESS.md-ро хон. Ин версия UI ва backend-и корӣ дорад; аз нав насоз. git status ва commit-и охиринро санҷ, тағйироти корбарро нигоҳ дор. Аввал item-и иҷронашудаи навбатиро аз PROGRESS.md ҳал кун, санҷиши мувофиқро иҷро карда commit соз ва checkpoint-ро нав кун. Як агент, муоширати тоҷикӣ, токенҳои сарфакорона. Маълумоти demo дар local_data аст; онро барои идома ҳазф накунед. Secrets ба repo ё чат нараванд. Агар муҳит нав бошад, launcher dependency ва базаи нави demo-ро омода мекунад; рамзи нав чоп мешавад.
